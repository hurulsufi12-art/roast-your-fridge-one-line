A one-line roast of my fridge, written for the
[One Line, One Laugh: Roast Your Fridge](https://make.fun/bounty/u-suzy-one-line-one-laugh-roast-your-fridge-f1063521)
bounty on make.fun.

> My fridge's ice maker only works when guests arrive, so even its cold shoulder needs an audience.

## Run

```sh
python3 main.py
```

This writes the single roast line to `/output/entry.txt` (97 characters,
no trailing newline). Python 3.13, standard library only, no network.
